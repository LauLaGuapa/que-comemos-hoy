# ¿Qué comemos hoy?

Recetario personal con parámetros de Thermomix, menú semanal y modo cocina paso a paso con temporizadores.

- Es una aplicación web instalable (PWA): sin dependencias ni paso de compilación.
- Las recetas **no** están en este repositorio: viven solo en el móvil de quien la usa (se importan y exportan como JSON desde la propia app).

## Publicar

En el repositorio: Settings → Pages → Source: *Deploy from a branch* → rama `main`, carpeta `/ (root)`.
